ModpackManager

Registers modpacks and dispatches their lifecycle hooks. Supports three dispatch styles: notify (TriggerHook), veto (CheckGate), and accumulate (SumHook).

Functions​

RegisterModpack​

</>
ModpackManager:RegisterModpack(modpack: ModuleScript) → ()

Requires and registers a modpack, making its hooks eligible for dispatch.

TriggerHook​

</>
ModpackManager:TriggerHook(
hook: Hooks,
...: any--

Arguments passed to each modpack's hook handler

) → ()

Calls the given hook on every registered modpack that implements it. Return values are discarded — use this for fire-and-forget lifecycle notifications.

CheckGate​

</>
ModpackManager:CheckGate(
hook: GateHooks,
...: any--

Arguments passed to each modpack's hook handler

) → boolean--

False if any modpack vetoed the action

Calls the given gate hook on every registered modpack that implements it, stopping at the first modpack that returns false. Modpacks that return nothing (or true) do not block the action.

SumHook​

</>
ModpackManager:SumHook(
hook: SumHooks,
...: any--

Arguments passed to each modpack's hook handler

) → vector--

The sum of every modpack's contribution

Calls the given hook on every registered modpack that implements it and sums their returned vectors. Modpacks that return nothing contribute zero.
