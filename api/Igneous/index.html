Igneous

Lightweight, modular FPS framework for Roblox providing core weapon mechanics with a hook-based modpack system

Types​

Firemode​

</>
type Firemode = "Semi" | "Auto" | "Burst"

Represents the three hardcoded weapon firemodes

LockAxes​

</>
type LockAxes = {
X: boolean,
Y: boolean,
Z: boolean
}

Which axes of the viewmodel's rotation should stay frozen relative to the camera.

RecoilData​

</>
type RecoilData = {
Vertical: number,
Horizontal: number
}

The magnitude of vertical and horizontal recoil applied per shot.

RuntimeState​

</>
type RuntimeState = {
Lock: LockAxes?,
Offset: vector?,
IsAiming: boolean,
Accuracy: number,
MaxSpread: number,
Range: number,
Cooldown: number,
Recoil: RecoilData
}

Mutable per-weapon state that modpacks can read and change at runtime via SetLock, SetOffset, SetAiming, and UpdateData, seeded from the weapon's Data on creation.

StagedReloadStage​

</>
type StagedReloadStage = {
Name: string,
Duration: number,
Cancellable: boolean,
AmmoTransfer: number?,
CanFireAfter: boolean
}

A single stage in a Staged reload. AmmoTransfer moves that many rounds from Reserve to Amount when the stage completes; omit it for stages with no ammo movement (e.g. racking a bolt). CanFireAfter controls whether the weapon may fire once this stage completes, or must wait for a later stage.

SimpleReloadData​

</>
type SimpleReloadData = {
Type: "Simple",
Duration: number,
Cancellable: boolean
}

A single wait-then-fill reload with no intermediate stages.

StagedReloadData​

</>
type StagedReloadData = {
Type: "Staged",
Stages: {StagedReloadStage}
}

A reload made up of ordered stages, each independently cancellable and able to gate firing and ammo transfer.

ProgressiveReloadData​

</>
type ProgressiveReloadData = {
Type: "Progressive",
Duration: number,
AmountPerCycle: number,
Cancellable: boolean
}

A reload that repeats a single cycle, adding AmountPerCycle rounds each time, until full or out of reserve. Used for pellet-fed or single-load weapons.

ReloadData​

</>
type ReloadData = SimpleReloadData | StagedReloadData | ProgressiveReloadData

A weapon's reload configuration, set via Data.Reload.

AmmoData​

</>
type AmmoData = {
Amount: number,
Max: number,
Reserve: number
}

A weapon's current ammo state.

Hooks​

</>
type Hooks = "OnEquip" | "OnUnequip" | "OnFireStart" | "OnFireEnd" | "OnFire" | "OnProjectileFire" | "OnAmmoChange" | "OnAimStart" | "OnAimEnd" | "OnCameraUpdate"

Notify hooks: dispatched to every modpack that implements them, return values discarded.

GateHooks​

</>
type GateHooks = "OnBeforeFire" | "OnBeforeAim" | "OnBeforeReload"

Veto hooks: any modpack returning false blocks the action.

SumHooks​

</>
type SumHooks = "OnCameraUpdate"

Accumulate hooks: every modpack's returned vector is summed.
