# Templates

This page contains the templates you need for Igneous viewmodels, data modules and modpacks.

- **Viewmodel**: what a viewmodel Model needs to contain, and where Igneous parents it
- **Modpack**: the hook surface, the four dispatch styles, providers, extensions and firemodes
- **Data Module**: every field a weapon's Data module can define, and which modpack reads it

Each one has its own page in the sidebar.
